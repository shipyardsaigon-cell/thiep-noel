# 🎄 Thiệp Giáng Sinh

Thiệp Giáng sinh làm bằng HTML, CSS và JavaScript, trong series **Code cùng Shipyard** (học lập trình web cho học sinh cấp 2).

👉 Mở thiệp: https://shipyardsaigon-cell.github.io/thiep-noel/

## Có gì trong thiệp
- Phong bì đỏ bấm vào thì mở, thiệp trượt ra (CSS `transition`, `transform`)
- Cây thông vẽ bằng CSS, đèn nhấp nháy và ngôi sao phát sáng (`@keyframes`)
- Tuyết rơi do JavaScript tạo ra (`setInterval`, `Math.random`)
- Lời chúc hiện ra từng chữ, kèm nhạc chuông "Jingle Bells" (Web Audio API)
- Tự tạo thiệp của em: nhập tên người nhận, người gửi, lời chúc và lấy link để gửi

## Gửi thiệp có tên
Thêm tên vào cuối link, ví dụ:

```
https://shipyardsaigon-cell.github.io/thiep-noel/?to=Mẹ&from=Minh An
```

Toàn bộ thiệp nằm trong một file `index.html`, em có thể tải về, mở bằng Notepad hoặc TextEdit để sửa màu, sửa lời chúc rồi mở lại bằng trình duyệt.
